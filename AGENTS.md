# Working preferences

- Work directly on `main` and commit and push requested changes to `origin/main`, unless the user explicitly asks for a different workflow.
- Skip all tests by default, as explicitly requested by the user. Do not run test suites, browser tests, smoke tests, or other automated test commands unless the user later asks for them. Source inspection and reviewing the changes are permitted.
- Preserve the original exported UI, layouts, responsive behavior, and interactions. Make only the requested changes; do not redesign the site when updating content or fixing a section.
- Keep Circle branding and neutral concept content. Do not restore previous business branding, affiliations, contact details, project claims, or media.
